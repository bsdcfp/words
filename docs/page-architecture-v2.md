# 页面架构 V2

日期：2026-05-31
来源：苏格拉底讨论收敛

---

## 用户可见概念

| 用户看到的 | 含义 | 用户不需要知道的 |
|-----------|------|-----------------|
| 单词书 | 高考3500 / 雅思等 | — |
| List | 一组 9 个词 | micro-list、group |
| 进度 | 圆点表示 | 具体 X/9 数字 |
| 今日目标 | 几个 list | 训前检测机制 |

用户界面上只出现"List"。micro-list（3 词一组）和 group（2 个 list = 18 词）是纯内部概念，不在任何 UI 文案中出现。

## 小程序导航策略

采用 **系统默认导航栏 + 页面主体完全自定义**。

更准确的描述是：

> 系统导航承载容器级导航与安全区适配；页面主体承载产品体验与视觉表达。

### 决策

- 保留微信小程序默认导航栏，不使用全局 `navigationStyle: custom`。
- 默认导航栏负责状态栏、胶囊按钮、刘海屏、安全区、系统标题颜色等平台适配。
- 页面主体从系统导航栏下方开始，卡片、按钮、学习流、深色/浅色主题全部由产品自定义。
- 单页应用内的二级页面仍保留业务返回按钮，用于返回上一个内部页面，而不是总回首页。

### 原因

- 小程序真实设备差异大，自定义导航容易引入状态栏遮挡、胶囊重叠、顶部留白和滚动晃动。
- 默认导航栏是微信平台最稳定的适配边界，可以降低真机发布风险。
- 我们的核心体验在学习页面、卡片层级、节奏和反馈，不在复刻系统顶部区域。

### 执行边界

- 可以自定义页面内部标题、进度圆点、底部操作区和学习沉浸视觉。
- 不再把状态栏、微信胶囊按钮、系统导航高度纳入页面像素级复刻范围。
- Reference 图只作为页面主体视觉参考，顶部系统区域以微信默认导航为准。

## 每日学习主流程

```text
打开小程序
→ 首页（进度 + 继续按钮）
→ 训前检测（一次性筛出今日所有不熟词）  ← 任意环节可暂停
→ 按 list 逐个学习                       ← 任意环节可暂停
  → 识记场景（3 词一组精学）
  → 回忆场景（本组复习 → 听音辨义 → 看中文回忆英文）
  → 混组复习（list 内 / group 内）
  → list 完成动画（不出报告，不打断心流）
→ 今日目标全部完成
→ 错词复习引导（可做可跳）
→ 庆祝页（今日总结 + 奖励）

暂停后回来 → 首页显示"继续学习" → 从暂停位置恢复
```

## 训前检测

### 机制

- 每天开始学习时，一次性筛出今日所有不熟词。
- 只展示英文，用户判断"认识"或"不熟"。
- 认识的词跳过（上滑飞走），从单词书补新词继续。
- 筛到今日目标数量的不熟词为止（比如 4 个 list = 36 个不熟词）。
- 筛完后，这些不熟词自动分成若干 list（每 list 9 词），进入学习流程。
- 筛完后当天不再进入训前检测。

### 交互

- 单卡片居中，只显示英文大字。
- 上滑 = 认识（卡片往上飞走）。
- 下滑 = 不熟（卡片往下落入"今日待学"堆）。
- 底部展示进度："已筛出 12/36"。

### 为什么这样设计

训前检测同时承担了 PhotoReading 的"影像扫描"功能——用户快速过一遍所有词，建立初始印象。筛完后直接进入精学，不需要单独的扫描步骤。

## 页面清单

### 非学习页面

| 页面 | 说明 |
|------|------|
| **首页** | 单词书进度 + 继续按钮 + 今日已学/目标 + 连续打卡天数。错词入口仅在晚间/早上展示。底部 Tab 到"我的"。 |
| **我的** | 个人中心。详见下方。 |
| **水平选择** | 首次使用选择学习水平。底部"不确定？做个测试"链接。 |
| **入学测** | 36 题两段式。可从水平选择页或"我的"进入。 |
| **测评结果** | 词汇量区间 + 起点建议。 |
| **阶段测** | 30 题三种题型。仅在"我的"提供入口，用户主动触发。 |
| **月度进展** | 按月打卡日历 + 已学词数。从"我的"进入。 |
| **训前检测** | 每日筛词。上滑认识/下滑不熟。 |
| **错词本** | 错词列表 + 开始复习按钮。从"我的"或首页晚间/早上入口进入。 |
| **庆祝页** | 今日目标全部完成后。今日总学词数、单词书进度、连续打卡、徽章。 |
| **词卡详情弹窗** | 点击任何词可查看完整信息（记忆图、例句、搭配等）。 |

### 学习页面（三个视觉场景）

| 场景 | 页面 | 说明 |
|------|------|------|
| **识记场景** | 识记页 | 英文+音标+释义居中，自动循环播放。记忆图/例句可展开。点击"记住了"翻下一个。 |
| **回忆场景** | 回忆页 | 本组复习、混组复习、看中文回忆英文共用。展示部分信息 → 2秒揭示。环节切换无提示。 |
| **听音场景** | 听音页 | 屏幕中心声波动画，不展示文字。自动播放。2秒后揭示。 |

学习页面支持浅色/深色主题切换，在"我的"设置。**默认使用浅色主题**，深色作为可选专注模式。

默认浅色的原因：

- 小程序日常打开频率高，浅色更接近微信默认容器和家长/学生预期。
- 默认导航栏也使用浅色时，页面顶部和系统容器更连贯。
- 深色原型可以作为沉浸学习主题保留，但不作为默认体验。

## "我的"页面结构

从上到下：

1. **单词书信息卡** — 书名、总词量、已学词量、进度百分比。点击切换单词书/水平。
2. **学习数据** — 今日学习词数、累计学习词数、连续打卡天数。
3. **学习日历** — 本周/本月打卡日历。
4. **错词本入口** — X 个错词待复习。
5. **测试区** — 入学测入口 + 阶段测入口。
6. **设置：每日目标** — 几个 list（1/2/3/...）。
7. **设置：播放循环次数** — 3/6/9/无限。
8. **设置：睡眠/起床时间** — 控制错词入口在首页的展示时间。
9. **设置：错词提醒开关** — 开/关。
10. **积分与排名** — 当前积分、排名（远期扩展）。
11. **数据重置** — 清除所有学习数据。

## 首页状态逻辑

首页的核心永远是：**单词书进度 + 一个主操作按钮**。

| 状态 | 主操作按钮 | 附加信息 |
|------|-----------|---------|
| **首次进入（未选水平）** | 选择学习水平 | 引导进入水平选择页 |
| 今天还没开始 | 继续 | 今日目标 X 个 list |
| 训前检测进行中 | 继续筛词 | 已筛 X/目标 |
| 训前检测完成，学习中 | 继续学习 | List X · 进度圆点 |
| 今日目标完成 | 明天继续 | 今日已学 X 词 |
| 隔天未完成 | 开始今日学习 | 昨天未完成提示 |

### 新用户首次进入

首次打开小程序，用户还没有选过单词书和水平。首页展示：

```text
欢迎！先选择你的学习水平

[选择学习水平]     ← 主按钮，进入水平选择页
```

水平选择页完成后回到首页，首页切换为正常的"进度 + 继续"状态。

水平选择页底部有"不确定？做个测试"链接，可进入入学测。入学测完成后自动设置水平并回到首页。

错词入口：仅在晚间（睡觉时间前 2 小时 → 当天结束）和早上（起床时间前 1 小时 → 起床后 3 小时）展示在首页。其他时间从"我的"进入。

## 错词复习

### 入口

- 每天学完今日目标后，自动引导"顺便过一下错词？"。可做可跳。
- 首页在晚间/早上展示错词入口。
- "我的"始终有错词本入口。

### 复习流程

复用回忆场景的模板（展示英文 → 2秒揭示中文）。不单独设计页面。

### 积分

做了给额外积分，不做不影响主进度和 list 完成状态。

## 学习流程内的状态流转

```text
训前检测完成
→ 取出前 3 个不熟词（micro-list 1）

micro-list 学习：
  识记 3 词
  → 本组复习（回忆→揭示）
  → 听音辨义（声波→揭示）
  → 看中文回忆英文（回忆→揭示）

list 内混组复习节奏：
  micro-list 1 完成 → 不触发混组
  micro-list 2 完成 → 触发 1+2 混组
  micro-list 3 完成 → 触发 1+2+3 混组
  → list 完成动画（圆点全亮 + 微振动）

group 内混组复习：
  list A + list B 都完成 → 触发 A+B 混组
  （只相邻配对，不跨组反复）

今日目标完成：
  → 错词复习引导（可做可跳）
  → 庆祝页
```

## 进度展示规则

- 学习页面内：用圆点表示当前 micro-list 的进度（已完成=实心、当前=脉动、未完成=空心）。
- 首页：展示单词书进度（数字："120/3500"）和今日已学/目标。
- 训前检测：展示"已筛出 X/目标"。
- 不在学习页面展示 "X/9"、"第 3 组"等数字。

---

## 全局暂停

暂停是全局能力，不限于某个环节。用户在学习流程中的**任何时刻**都可以暂停：训前检测、识记、本组复习、听音辨义、看中文回忆英文、混组复习。

### 暂停方式

按专注设计指南，学习页面隐藏了返回按钮。暂停通过手势触发（长按屏幕或左边缘右滑），弹出暂停面板。

### 暂停面板

```text
已学 X / 今日目标 Y 词

继续学习
暂停休息
调整计划
```

### 状态保存

暂停时系统记录当前精确位置：

- 训前检测：已筛出多少词、当前单词书位置
- 识记：当前 micro-list 第几个词
- 复习/听音/回忆：当前环节、当前词、当前题
- 混组复习：当前混组队列位置

当天再次进入时，从暂停位置继续，不丢失进度。

---

## 关键设计原则

1. **用户只看到 List。** micro-list 和 group 不出现在任何 UI 文案中。
2. **训前检测 = 影像扫描。** 一次性筛完今日所有词，同时建立初始印象。
3. **学习三场景统一体验。** 识记、回忆、听音三个模板覆盖所有学习环节，环节切换无提示。
4. **list 完成不出报告。** 只做完成动画，不打断心流。今日目标全部完成才出庆祝页。
5. **错词不阻塞推进。** 错词复习可选，给额外积分，不影响主进度。
6. **错词首页入口有时间窗口。** 晚间和早上在首页展示，其他时间只在"我的"。
