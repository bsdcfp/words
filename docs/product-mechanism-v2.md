## 产品定位

V2 的首要目标调整为：

**完成一本单词书。**

核心痛点：**词太多，学不完。** 推进速度优先。

产品主逻辑不再围绕艾宾浩斯遗忘曲线排程展开，而是围绕：

1. 选择单词书 / 学习水平（可选入学测精确定位）
2. 按 list 推进，每个 list 内按 3 个 micro-list 学习
3. 新词学完 = list 完成 = 主进度推进
4. 错词进入统一错词本，**复习可选，不阻塞主进度**
5. 用积分和进度鼓励继续完成单词书

V2 可以暂时牺牲：

- 艾宾浩斯遗忘曲线长周期排程（不再作为主逻辑）
- 超期降级机制
- 到期复习优先级排序
- 例句训练题型
- 阅读迁移

V2 需要保留：

- 发音与跟读
- 记忆图/场景
- 例句/搭配的轻量用法辅助
- 错词本与复习
- 听音辨义
- 看中文回忆英文

### 当前支持

- 高考课标 3500 词（教育部课标附录 2）

### V2 新增

- 雅思词书（待建数据源）

### 暂不考虑

- 托福

### 单词书结构

每本单词书由若干 list 组成。用户按 list 顺序推进，完成一本书即为完成主目标。

层级定义：

| 概念 | 数量 | 产品含义 |
|------|------|----------|
| micro-list | 3 个词 | 最小学习单元，学完立刻做本组复习、听音辨义、看中文回忆英文 |
| list | 3 个 micro-list = 9 个词 | 一个短学习闭环，内部做 list 内混组复习 |
| group | 2 个 list = 18 个词 | 一个更大的复习闭环，两个 list 完成后做 group 内复习 |

## 词汇量测试

V2 将原有的词汇量测试拆分为两种独立测试：

### 入学测

入学测**不是必须门槛**，用户可以跳过直接手动选择水平。入学测的价值是精确定位起点。

入口位置：

- 水平选择页底部："不确定？做个测试" 链接
- "我的"设置区：随时可重测

#### 核心用途

判断学生应该从单词书的哪个位置开始学。

#### 测试形式

- 题型：看英文 → 选中文释义
- 选项：1 个正确释义 + 3 个干扰释义 + 1 个"不认识"
- 干扰释义不使用同一英文词的其他词性释义

#### 题量与结构

固定 36 题，分两段完成：

- 前 18 题：平均分层抽样，每层 6 题
- 后 18 题：根据前半段表现，追加到临界层级

每次进入入学测都重新抽题，同一次测试内题目稳定。

#### 分层与通过阈值

分层按单词书内容确定。以高考课标词为例：

| 层级 | 词量 | 通过阈值 |
|------|------|----------|
| 义务教育基础词 | 1500 | 80% |
| 高中必修词 | 499 | 70% |
| 选择性必修词 | 1001 | 60% |

#### 学习起点映射

按"第一个未通过层"决定起点：

- 义务教育基础词未通过 → 从义务教育基础词开始
- 义务教育通过，高中必修未通过 → 从高中必修词开始
- 前两层通过，选择性必修未通过 → 从选择性必修词开始
- 三层都通过 → 从选择性必修词继续巩固

#### 输出形态

对学生展示词汇量区间 + 置信说明，不展示假精确的单点数字。

示例：

```text
当前词汇量约 1500-2100。
这是初测估计，后续会结合真实学习表现校准。
建议从高中必修词开始。
```

#### 区间估算

- 上限：通过层全计 + 未通过层按正确率折算
- 下限：通过层全计 + 未通过层按正确率 × 0.5

#### 临界层追加规则

- 某层前 6 题答对 3 或 4 题 → 该层为临界层
- 单个临界层 → 追加 18 题
- 两个临界层 → 低层 12 题 + 高层 6 题
- 基础层明显不稳（≤2/6）→ 后 18 题全投基础层
- 无临界层 → 按最高通过层和最低失败层的边界分配

#### 用户状态写入

```js
{
  vocabularyAssessment: {
    completedAt,
    startLevel,
    vocabularyRange: { lower, upper },
    layerStats: {
      foundation: { total, correct, unknown, wrongChoice, accuracy, passed },
      required: { ... },
      selective: { ... }
    }
  }
}
```

#### 允许手动调整

用户可在"我的"中手动调整起点，不被测试结果锁死。

### 阶段测

阶段测用于评估已学词的掌握程度。**完全由用户主动触发，不主动弹出。**

#### 触发方式

- 只在"我的"里提供入口，用户想测就测
- 不在首页弹出，不打断学习节奏
- 不设触发条件（去掉"每 5 个 list 触发"的规则）

#### 测试范围

只测已学过的词。从用户已完成 list 中的词里抽题。

#### 测试题型

与入学测一致：看英文选中文释义。

额外增加：

- 听音辨义：听发音选中文释义
- 看中文回忆英文：展示中文，用户回忆英文（语音或自评）

三种题型混合出题，每种各占约 1/3。

#### 题量

固定 30 题（每种题型约 10 题）。

#### 输出

- 掌握率：按已学词总量折算
- 薄弱词列表：答错的词自动加入错词本
- 建议：是否需要降速推进或加强复习

#### 与入学测的区别

| | 入学测 | 阶段测 |
|---|--------|--------|
| 目的 | 确定起点 | 评估效果 |
| 触发 | 首次进入 | 每 N 个 list |
| 范围 | 全词书分层抽样 | 仅已学词 |
| 题型 | 看英文选中文 | 三种混合 |
| 输出 | 起点 + 词汇量区间 | 掌握率 + 薄弱词 |
| 强制 | 可跳过（手动选水平） | 可跳过 |

## List 与每日目标配置

- 每个 micro-list 固定 3 个词。
- 每个 list 固定 3 个 micro-list = 9 个词。
- 每个 group 固定 2 个 list = 18 个词。
- list 不再是可变长度概念。
- 用户配置的是每日目标：每天完成几个 list。
- 默认每日目标：1 个 list = 9 个词。
- 配置入口放在"我的"里，和单词书配置放在一起。
- 可配置为 1 / 2 / 3 个 list，后续可扩展。

## 首页设计

首页目标是回答一个问题：**下一步该做什么？**

### 首页任务优先级

1. 继续未完成 list
2. 睡前 / 晨间错词复习
3. 开始新 list

首页不展示复杂状态机，只显示当前最高优先级任务。

### 页面结构

- 顶部：当前单词书、连续学习天数、"我的"入口
- 主卡片：当前任务（继续 list / 错词复习 / 新 list）
- 进度信息：单词书进度、当前 list 进度
- 主按钮：对应当前任务的操作
- 底部 Tab：单词、我的

### 文案原则

- 强调"完成单词书"的推进感
- 不出现艾宾浩斯、复习节点等术语
- 错词复习以轻提示呈现，不强弹窗

### 示例文案

继续 list：

```text
List 3 · 已完成 2/3 个 micro-list
继续学习
```

错词复习（睡前窗口）：

```text
今天有 8 个错词待复习
开始复习
```

新 list：

```text
单词书进度 120/3000
开始 List 4
```

隔天未完成提示：

```text
昨天 List 3 没学完（2/3 个 micro-list）
今天开始新 List · 是否调小每日目标？
```

## 每个 micro-list 学习流程

每个 micro-list 固定 3 个词，默认流程：

```text
单词识记
→ 本组复习
→ 听音辨义
→ 看中文回忆英文
→ 混组复习
```

### 单词识记

目标：低压力地反复看和听，快速建立初始英中映射。

展示内容：

- 英文单词
- 词性
- 中文释义
- 音标
- 发音（自动循环播放）
- 记忆图/场景
- 例句/搭配按钮，默认不展开

#### 播放规则

- 进入识记卡片后自动循环播放发音。
- 循环次数是用户配置项，默认 3 次。可选 3 / 6 / 9 / 无限。
- 配置入口放在"我的"。
- 去掉独立播放按钮，发音完全由自动循环驱动。
- 播放完设定次数后等待用户操作。

#### 交互规则

- 学生点击"已记住"：进入下一个词。
- 学生点击"还不熟"：立即再播放一轮（一轮 = 用户设定次数，默认 3 次）。
- "还不熟"不进入错词本，只影响当前播放。
- 3 个词都看完后，统一进入本 micro-list 复习。

#### 跟读检测

- 默认鼓励跟读。
- 如果没有检测到声音，只轻提示一次"试着跟读一下"。
- 提示可关闭。
- 不强制跟读。
- 允许默读，也允许只靠耳朵和嘴巴学习。

### 本组复习

目标：验证"看到英文 → 回忆中文释义"。

V2 改为"回忆→揭示"模式，不再使用选择题：

- 展示英文单词和音标。
- 不展示词性和中文释义。
- 自动播放发音。
- 2 秒内没有点击"记住了"，自动展示词性和中文释义。
- 学生点击"记住了"：视为通过。
- 超时自动揭示后：学生可点击"记住了"（仍视为通过）或系统自动进入下一个。

设计原则：快感来自速度，直观来自一目了然。

#### 通过方式

1. 收到语音输入且正确（中文释义命中任意一个即可）。
2. 点击"记住了"（视为自评通过，记录为 selfAssessed）。

#### 未通过处理

- 超时且未点击 → 自动展示答案 → 加入错词本 → 自动进入下一个。

### 听音辨义

目标：验证"听到发音 → 回忆中文释义和词性"。

- 自动播放英文发音。
- 页面不展示单词拼写和音标，避免从文字猜答案。
- 播放节奏：播放一次 → 等待。用户可设置一次性播放 N 次再等待。
- 设定次数内说对一次即可通过。

#### 通过方式

1. 语音识别：说出中文释义和词性，或词性和中文释义，命中即通过。
2. 点击"已记住"：视为自评通过。

#### 未通过处理

- 设定次数内一次没对 → 自动展示答案 → 加入错词本 → 自动进入下一个。

### 看中文回忆英文

目标：验证"看到中文释义 → 回忆英文单词"。

- 展示中文释义和词性。
- 不展示英文单词。
- 2 秒内没有点击"记住了"，自动展示英文单词。

#### 通过方式

1. 语音识别：英文发音识别正确即可。
2. 点击"记住了"：视为自评通过。

#### 未通过处理

- 超时自动揭示 → 加入错词本 → 自动进入下一个。

### 三个验收环节的统一规则

适用于：本组复习、听音辨义、看中文回忆英文、混组复习。

#### 默认模式：自评通过

| 通过方式 | 说明 | 错词本 |
|---------|------|--------|
| 点击"记住了" | 视为通过，记录为 selfAssessed | 不加入 |
| 超时/未通过 | 自动展示答案 | 加入 |

默认模式追求推进速度，用户自评通过即可。自评的可信度由阶段测兜底检验。

#### 可选模式：语音验证

用户可在"我的"中开启语音验证模式：

| 通过方式 | 说明 | 错词本 |
|---------|------|--------|
| 语音正确 | 中文释义命中任意一个 / 英文发音正确 | 不加入 |
| 点击"记住了" | 仍可用，记录为 selfAssessed | 不加入 |
| 超时/未通过 | 自动展示答案 | 加入 |

语音模式和自评模式可以在同一界面共存，用户随时切换。开启语音模式不禁用"记住了"按钮（适应不方便出声的场景）。

内部记录区分 voiceVerified 和 selfAssessed，后续统计可信度有差异。

## 混组复习

### micro-list / list / group

- 每个 micro-list 固定 3 个词。
- 每 3 个 micro-list 组成一个 list。
- 一个 list 包含 9 个词。
- 每 2 个 list 组成一个 group。
- 一个 group 包含 18 个词。

### list 内的节奏

整体节奏：本组复习 → 听音辨义 → 看中文回忆英文 → 混组复习。

一个 list 内有 3 个 micro-list，混组复习按以下节奏推进：

1. 第 1 个 micro-list 学完：第 1 个 micro-list 单独复习一次。
2. 第 2 个 micro-list 学完：第 2 个 micro-list 单独复习一次，然后 2+1 混组复习。
3. 第 3 个 micro-list 学完：第 3 个 micro-list 单独复习一次，然后 3+2+1 混组复习一次。

这里接受第 3 个 micro-list 在 list 内少一次混组复现，不强行追求 3 个 micro-list 的复现次数完全一致。理由是：避免第 3 个 micro-list 在刚学完后连续进入多轮混组复习，优先保证推进速度和心流。

### group 内的节奏

两个 list 成对完成后，做一次 group 内混组复习：

- List A + List B
- List C + List D
- List E + List F

不会把已完成 group 内复习的 list 再拿来和下一个 list 反复组合。只有配对的另一个 list 也完成后，才触发 group 内复习。

### 混组复习题型

混组复习只做看词辨义（看英文选中文释义）。

## 错词本机制

### 错词本数量

学生端只有一个错词本。

### 错词来源

以下环节失败会进入错词本：

- 本组复习（超时未通过）
- 听音辨义（设定次数内未通过）
- 看中文回忆英文（超时未通过）
- 混组复习（答错）

"还不熟"不算错词，只影响当前播放。

### 错词清除

- 错词复习时，点击"已记住"即可从错词本移除。
- 不区分语音验证通过 / 自评通过，都视为移除。
- 历史错题记录保留，但学生端不展示"曾错过"。
- 历史记录仅用于报告和后续策略。

### 错词排序

1. 当前 list 的错词优先
2. 再按出错时间排序

### 睡前 / 晨间提醒范围

提醒错词本里所有未清除错词，排序仍然是当前 list 错词优先。

## 错词复习（第一版）

第一版简化实现，去掉时间窗口、调整策略、错过计数器等复杂逻辑。

### 第一版做法

- 错词本始终可用，用户随时可以进入复习。
- 首页在有错词时展示一个入口："X 个错词待复习"。
- 不做时间窗口判断，不做定时提醒。
- 错词复习给额外积分，但不影响 list 完成状态。

### 后续迭代方向

以下功能在用户量起来后再考虑：

- 睡前/晨间复习窗口（需要设置页、时间判断逻辑）
- 错词提醒策略（连续错过提示、暂停/恢复开关）
- 基于错词数量的自动调整策略

## List 暂停与隔天处理

### 当天暂停

- 学生可以主动暂停（"申请暂停"）。
- 当天再次进入时，继续当前 list，不丢失进度。

### 隔天回来

如果昨天 list 没完成：

- 不强制继续昨天 list。
- 今天开始新的 list。
- 昨天已经学过的新词不重复学习。
- 首页提示用户：昨天未完成，是否需要调小每日目标。
- 昨天产生的错词是否复习，取决于用户的错词提醒策略。

### 申请今日完成

- 用户可以在 list 进行中申请"今日完成"。
- 给一个调整计划提示：是否调小每日目标。
- 提示"需要申请老师介入吗？"（对接 AI Agent 老师，远期功能）。

## 完成标准与状态

### 完成标准

**新词学完 = list 完成 = 主进度推进。**

错词复习是额外奖励，不是完成的前提。用户新词学完就看到进度增长，不会因为没做错词复习而"永远差一点"。

### List 状态

系统内部记录每个 list 的状态：

| 状态 | 说明 |
|------|------|
| `in_progress` | 新词正在学习中 |
| `completed` | 新词全部学完，list 完成 |
| `abandoned` | 隔天未完成，已开始新 list |

### 单词书进度口径

- 新词学完，单词书进度立刻增加。
- 不存在"待巩固"状态，完成就是完成。

## 奖励与积分

奖励分为主线和额外：

| 类型 | 触发条件 | 奖励 |
|----|---------|------|
| 主线 | 新词学完（list 完成） | 基础积分 + 进度推进 |
| 额外 | 错词复习 | 额外积分（锦上添花） |

主进度只看新词完成。错词复习给额外积分，但不影响 list 完成状态和单词书进度。

### 连续打卡

保留 V1 的连续打卡和徽章机制：

- 连续 1 天：起步徽章
- 连续 3 天：三日连学
- 后续扩展更多徽章

## 学习项定义

沿用 V1 定义。V2 的最小学习单位是：

```text
英文词 lemma + 词性 pos + 中文释义块
```

同一英文词不同词性算不同学习项，各占 micro-list 的名额。

### 展示规则

- 标题只显示英文词。
- 词性放在中文释义前。
- 同词不同词性连续出现时，轻提示"同词不同词性"。

### 选择题规则

- 单选题的错误选项不使用同一英文词的其他词性释义。

## 发音策略

### 形态

- 默认使用英音。
- V2 不提供英音/美音切换。
- 识记页展示音标；听音辨义页不展示拼写和音标。

### 音频来源

- 测试号阶段：动态拼接在线词典发音链接（有道）。
- 上线前升级：迁移到自有或授权音频资源，走 CDN/云存储。

### 循环播放

- 默认一轮播放 3 次。
- 可配置为 3 / 6 / 9 / 无限。
- 配置入口放在"我的"。

## 我的 Tab

- 积分与排名（远期）
- 设置入口：
  - 学习水平 / 单词书
  - 每日目标（1/2/3 个 list）
  - 播放循环次数（3/6/9/无限）

  - 错词提醒开关
  - 数据重置
