## 页面特征

个人中心，有 Tab 栏（"我的" 选中态）。从上到下：单词书卡、学习数据、日历、错词入口、测试区、设置区。可滚动。

## 顶部导航栏右侧图标组

```
位置: 右上角，与"我的"标题对齐
图标数量: 3 个
图标间距: 16rpx
每图标尺寸: 40rpx
颜色: --text-secondary
图标说明:
  ① 日历图标（月度进展入口，跳转 16 页）
  ② 搜索/铃铛图标（功能待定，可为通知中心）
  ③ 齿轮/设置图标（快捷入口）
```

```
宽度: 670rpx

## 学习数据区规格

```
区标题"学习数据": Label 24rpx w600 --text-label，margin-bottom 16rpx
三列统计布局（与庆祝页共用）:
  每列有列标题图标（约 20rpx, --text-label）
  今日学习列图标: 火焰图标
  累计学习列图标: 书本图标
  连续打卡列图标: 火焰/星形图标

```

## 设置行规格

```
