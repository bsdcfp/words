## 页面特征

本组复习/混组复习/看中文回忆英文共用此模板。此为"揭示前"状态：只展示英文+音标+声波，释义隐藏。

│  ● ● ● ● ● ○ ○ ○ ○             │ 进度圆点
├─────────────────────────────────┤

## 与识记页（07）的区别

| 项目 | 识记页 | 回忆页-揭示前 |
|------|--------|-------------|
| 释义 | 始终展示 | 隐藏，等待揭示 |
| 底部提示 | "轻点再听" | "⏱ 2 秒后揭示" |
| 声波行为 | 循环播放 N 次 | 播放 1 次后等待 |

## 倒计时提示

```
"⏱ 2 秒后揭示"
⏱ 图标: 20rpx, --text-label
文字: Small 22rpx --text-label
2 秒倒计时可用圆弧进度环替代文字（可选增强）
```

## "记住了"按钮行为

- 揭示前点击 = 高置信通过（用户在 2 秒内确认记住了）
- 记录为 `selfAssessed: true, highConfidence: true`
- 点击后直接切换下一个词
