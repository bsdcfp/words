# 13-wrong-words 错词本页规格

Reference: `dark/13-wrong-words.png`
共享 Token: `00-global-design-tokens.md`

## 页面特征

列表页，**无 Tab 栏**（从首页错词提示条进入，属于功能子页面）。顶部统计+开始复习按钮，下方错词列表，底部鼓励文案。

## 布局

```
┌─────────────────────────────────┐
│ 状态栏                           │
├─────────────────────────────────┤
│ ‹    错词本              编辑    │ 返回(64rpx) + 标题 H3 36rpx 居中 + 右上编辑
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │ 📋 8 个错词待复习             │ │ H3 36rpx --text-primary
│ │    优先复习当前 List 的词      │ │ Caption --text-secondary
│ │ ┌────── 开始复习 ────────────┐│ │ CTA h80rpx --accent
│ │ └──────────────────────────┘│ │
│ └─────────────────────────────┘ │ 卡片 r40rpx
├─ gap: 16rpx ────────────────────┤
│ 💡 错词会随复习自动清除，不影响... │ Small 22rpx --text-label 居中
├─ gap: 24rpx ────────────────────┤
│ ┌─────────────────────────────┐ │
│ │ abandon   v. 放弃；抛弃  待复习│ │ 列表行 h96rpx
│ │ hesitate  v. 犹豫；迟疑  待复习│ │
│ │ benefit   n. 好处；益处  已记住│ │ "已记住" = --success
│ │ recover   v. 恢复；痊愈  待复习│ │
│ │ sacrifice n. 牺牲；奉献  待复习│ │
│ │ ordinary  adj. 普通的   已记住│ │
│ └─────────────────────────────┘ │
├─ gap: 24rpx ────────────────────┤
│ 🏆 坚持复习，记得更牢              │ Small --text-label
│    已记住的词会自动从错词本移除     │ Small --text-label
├─────────────────────────────────┤
│ Tab 栏                           │
└─────────────────────────────────┘
```

## 列表行规格

```
宽度: 670rpx
高度: 96rpx
背景: --bg-card
描边: 底部 1rpx solid --border-divider（最后一行无）
内边距: 0 36rpx
布局: flex, align-items center

左侧:
  单词: Body 30rpx w700 --text-primary
  释义: Body-S 28rpx --text-secondary, margin-left 24rpx

右侧状态标签:
  "待复习": pill r999rpx, bg rgba(217,119,87,0.15), text --accent, 22rpx w600
  "已记住": pill r999rpx, bg rgba(94,138,122,0.15), text --success, 22rpx w600
```

## "编辑"按钮

```
位置: 右上角，与返回按钮对齐
文字: Body-S 28rpx --text-label
功能: 进入多选模式，可批量标记"已记住"
```

## 统计卡片图标

```
左侧图标: 剪贴板+红色 ✕ 标记图标（表示错误/待复习）
尺寸: 48rpx
颜色: --accent（橙红色）
位置: 卡片内左侧，与文字垂直居中
```

## 提示条图标

```
"错词会随复习自动清除…" 左侧:
  图标: 叶子/植物图标
  尺寸: 16rpx
  颜色: --text-label
  右侧间距 8rpx
```

## 列表行右侧箭头

```
每行列表项右侧有 › 箭头，表示可进入单词详情：
  字号: Body-S 28rpx
  颜色: --text-label
  右对齐
```

## 列表卡片容器

列表区整体包裹在卡片容器中：

```
宽度: 670rpx
圆角: 40rpx
背景: --bg-card

```
