## 页面特征

全屏深色，无 Tab 栏。屏幕中心一张单词卡片，支持上滑（认识）/下滑（不熟）。底部展示筛词进度。

## 布局

```
┌─────────────────────────────────┐
│ 状态栏                           │
├─────────────────────────────────┤
│         训前检测                  │ Body 30rpx --text-secondary 居中
├─────────────────────────────────┤
│                                 │
│    ┌───────────────────────┐    │
│    │                       │    │ 卡片 560×720rpx r32rpx
│    │                       │    │ bg: --bg-card-elevated
│    │                       │    │ 描边: --border-card
│    │       harvest         │    │ Word 72rpx w900 居中
│    │                       │    │
│    │         🔊             │    │ 小播放图标 32rpx --text-label
│    │                       │    │
│    │    ↑上滑      ↓下滑    │    │ 箭头动画提示（首次显示）
```

## 卡片规格

```
宽度: 560rpx
高度: 720rpx
圆角: 32rpx
背景: --bg-card-elevated
描边: 2rpx solid --border-card
阴影: 0 24rpx 80rpx rgba(0,0,0,0.4)

单词: 垂直居中，Word 72rpx
播放图标: 单词下方 24rpx, 32rpx, --text-label
```

## 手势与动画

| 手势 | 动画 | 结果 |
|------|------|------|
| 上滑 > 100rpx | 卡片向上飞出 + 缩小，200ms ease-out | 标记"认识"，补新词 |
| 下滑 > 100rpx | 卡片向下落入，200ms ease-out | 标记"不熟"，计入今日待学 |
| 未超过阈值 | 卡片弹回原位，150ms | 无操作 |

## 滑动提示

- 首次进入显示箭头 + 文字（"↑上滑认识""↓下滑不熟"）
- 用户滑动过 3 次后自动隐藏提示
- 提示 opacity 0.5，不抢视觉焦点

## 底部进度

```
高度: 100rpx
背景: --bg-primary
布局: flex, justify-content space-between, padding 0 40rpx
左: "已筛出 12 / 36", Body-S 28rpx
  "12" 用 --text-primary w900
  "/ 36" 用 --text-label

```

## 滑动箭头颜色规格

| 箭头 | 颜色 | 说明 |
|------|------|------|
| 上滑↑（认识） | --success（dark `#5E8A7A` / light `#5E8A6A`） | 绿色向上箭头 |
| 下滑↓（不熟） | --accent（dark `#D97757` / light `#D4935A`） | 橙色向下箭头 |
| 箭头尺寸 | 约 32rpx 宽 × 40rpx 高 | |
| 标签布局 | 箭头下方文字分两行：第一行"上滑"/"下滑"，第二行"认识"/"不熟" | Caption 24rpx --text-secondary |

## 底部进度区补充规格

| 元素 | 规格 |
|------|------|
| "今日待学"右侧书本堆叠图标 | 书本堆叠小图标，约 32rpx，--text-label，位于"今日待学"文字右侧，margin-left 8rpx |

## 装饰气氛元素

| 元素 | 规格 |
