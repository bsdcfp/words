## 月历规格

```
容器: 670rpx r40rpx --bg-card
网格: 7 列均分
每格: 56rpx 正方形
打卡日: 圆形背景 rgba(94,138,122,0.25), 文字 --success
今日: 圆形背景 --accent, 文字 #141413（dark）/ #FFFFFF（light）
未打卡: 无背景, --text-secondary
溢出日期（上月末/下月初）: 无背景, --text-disabled（透明度更低）
月份切换: ‹ ›箭头, Body 30rpx --text-label, 当前月 --text-primary
```

## 月历图例

月历区右下角（或底部）有图例说明：

```
图例布局: 横向排列，右对齐
"已学习": 圆形 10rpx 填充 rgba(94,138,122,0.25) + 文字 Small 22rpx --text-secondary
"未学习": 圆形 10rpx 无背景 描边 --border-option + 文字 Small 22rpx --text-secondary
图例间距: 12rpx
```

## 折线/面积图规格（替代原柱状图定义）

```
图表类型: 折线图（line chart）+ 面积填充（area chart）
数据维度: 按周分组（X 轴为第1周、第2周、…第5/6周、本周）
容器高度: 200rpx
折线:
  颜色: --success（dark `#5E8A7A` / light `#5E8A6A`）
  线宽: 2rpx
  折线节点: 圆形 8rpx, 填充 --success
面积填充:
  颜色: rgba(94,138,122,0.15)（dark）/ rgba(94,138,106,0.15)（light）
X 轴标签: "第1周" "第2周" … "本周"，Small 22rpx --text-label
数据点标注: 各节点上方标注词数，Small 22rpx --text-label
底色轨道: 无（折线图不需要底色柱）
```

## 统计区书堆图标

```
位置: "620 词"数字右侧或右上角，装饰性
图标: 书本堆叠图标，约 48rpx
颜色: --text-label opacity 0.5
```

pill r999rpx
