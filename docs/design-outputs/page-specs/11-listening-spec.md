## 页面特征

不展示任何文字，屏幕中心只有声波动画。自动播放发音，用户听音后回忆中文释义。2 秒后底部推入释义。

## 声波动画规格（主题差异）

### Dark 主题声波

```
外圈: 160rpx 直径, 描边 2rpx --success opacity 0.2, 脉动缩放 1.0→1.15
中圈: 120rpx 直径, 描边 2rpx --success opacity 0.4
内圈: 80rpx 直径, 填充 rgba(94,138,122,0.1)
中心波形: 5 条竖线, 高度随音频振幅变化
  播放中: 竖线随机高度抖动
  静止: 竖线等高
颜色: --success-bright
```

### Light 主题声波

```
实心圆: 160rpx 直径, 填充 --success（实心绿色）
中心播放按钮: 三角形图标, 约 48rpx, 白色 #FFFFFF
两侧横向波形线: 左右各 5–7 条水平短线, 高度随振幅变化, 颜色 --success opacity 0.5
外圈同心圆: 200rpx, 描边 2rpx --success opacity 0.15, 脉动
```

## 与回忆页的区别

| 项目 | 回忆页 | 听音页 |
|------|--------|--------|
| 中心内容 | 单词文字 72rpx | 声波动画 160rpx |
| 音标 | 展示 | 不展示 |
| 文字提示 | "2 秒后揭示" | "正在播放…" + "听发音，回忆中文释义" |
| 揭示内容 | 释义 | 释义（同） |

## 可点击重播

- 点击声波动画区域 = 重播发音
- 不用额外的播放按钮

## 释义区分隔行

参考图中释义卡片上方有一个分隔行：

```
"— ⏱ 2 秒后显示释义 —"
高度: 40rpx
布局: flex, justify-content center, align-items center
颜色: --text-label
字号: Small 22rpx
两侧 "—" 为装饰分隔线
```

## Light 底部额外提示

light 参考图底部 CTA 按钮下方有额外小字提示：

```
"提示将在 2 秒后显示"
字号: Small 22rpx
颜色: --text-label
居中，margin-top 12rpx
仅在揭示前显示，揭示后消失
```

## CTA 光晕

```
box-shadow: 0 16rpx 48rpx rgba(217,119,87,0.25)（dark）/ rgba(212,147,90,0.3)（light）
```
