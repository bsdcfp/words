# 02-level-select 水平选择页规格

Reference: `dark/02-level-select.png`
共享 Token: `00-global-design-tokens.md`

## 页面特征

全屏深色页面，无 Tab 栏。右上角"跳过"，底部"不确定？做个测试 ›"链接。6 个水平选项纵向排列，当前只有高中可选。

## 选项卡规格

| 状态 | 背景 | 描边 | 文字 | 图标 | 右侧 |
|------|------|------|------|------|------|
| 可选未选中 | --bg-input | --border-option | --text-primary w700 | 40rpx 图标 | 无 |
| 选中 | --bg-input | --border-option-selected 2rpx | --text-primary w700 | 40rpx | ✓ 36rpx --success-bright |
| 禁用 | --bg-input | --border-option | --text-disabled | 40rpx opacity 0.4 | 无 |

## 背景层规格

| 层级 | 规格 |
|------|------|
| 主背景色 | dark `#0B1A17` / light `#F5F0E8` |
| 纹理叠加 | dark `bg-ink-texture-dark.webp` opacity 0.15 / light `bg-landscape-light.webp` opacity 0.3–0.5（light 图可见明显山水淡纹理） |
| 无底部场景图 | 本页无书桌/山水场景，纯背景 |

## 装饰元素

| 元素 | 规格 |
|------|------|
| 标题下菱形分隔符 | 单个"◆"或"·"小菱形点，居中，约 16rpx，--text-label，位于标题与选项列表之间，margin-top 8rpx |
| 选项图标说明 | 小学: 书本图标；初中: 翻页书；高中: 毕业帽+植物；大学四/六级: 学士帽；考研: 建筑/柱形；各图标约 40rpx |

## Codex 检查表

- [ ] 无 Tab 栏，全屏页面
- [ ] 只有高中为可选态（--border-option-selected + ✓）
- [ ] 其他选项禁用态（opacity 0.4，不可点击）
- [ ] "跳过"在右上角，不是按钮，是文字链接
- [ ] "不确定？做个测试 ›" 可点击，跳转入学测
- [ ] 选中高中后直接进入首页（05），不弹确认
- [ ] light 主题背景有山水纹理叠加
