# Spec 完整性验证方法

## 目的

确认每份 page-spec 完整表述了对应 reference 图的所有可见元素，没有遗漏。

---

## 验证流程

### 步骤 1：逐层扫描 reference 图

按从上到下、从外到内的顺序，列出 reference 图中所有可见元素：

1. **背景层**：纯色 / 渐变 / 纹理 / 场景图
2. **状态栏**：时间、信号、电量
3. **导航栏**：返回、标题、右侧操作
4. **内容区**：逐个卡片/区块，每个卡片内逐个元素
5. **底部操作**：CTA 按钮、提示条
6. **固定层**：Tab 栏、浮动按钮
7. **装饰层**：图标、插图、动画占位

### 步骤 2：逐元素核对 spec

对照步骤 1 的元素清单，检查 spec 中是否包含：

| 检查项 | 说明 |
|--------|------|
| 元素是否存在 | spec 是否提到了这个元素 |
| 位置是否标注 | 在布局图或间距表中有没有位置 |
| 尺寸是否标注 | 宽高、字号、图标大小 |
| 颜色是否标注 | 引用了哪个 token 或给了具体色值 |
| 状态是否覆盖 | 选中/未选中、禁用、空态等 |
| 交互是否标注 | 点击跳转、hover 效果、动画 |

### 步骤 3：输出验证报告

格式：

```
✓ 元素名 — spec 中有完整描述
△ 元素名 — spec 提到但缺少具体参数（标注缺什么）
✗ 元素名 — spec 未提到（需补入）
```

### 步骤 4：补入遗漏

把 ✗ 和 △ 项补入 spec，重新验证直到全部 ✓。
