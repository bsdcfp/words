## 页面特征

半屏弹窗，从底部推出。上半部分仍可见当前学习页（单词+音标+声波），下半部分展示详情内容。

## 弹窗规格

```
位置: 从底部推出，覆盖约 55% 屏幕高度
顶部圆角: 40rpx
背景: --bg-card-elevated
上方遮罩: rgba(0,0,0,0.4)
内边距: 40rpx
可滚动: 内容超出时可向上滚动
```

## 弹窗顶部控件

| 元素 | 规格 |
|------|------|
| 拖拽把手（handle indicator） | 弹窗顶部居中，宽 40rpx，高 4rpx，圆角 2rpx，背景 --text-disabled，margin-top 12rpx，margin-bottom 16rpx |
| 折叠箭头 ∨ | 弹窗右上角，约 28rpx，--text-label，点击收起弹窗，绝对定位 right 40rpx top 16rpx |

## 内容区块分隔线

各内容区块（记忆场景 / 例句 / 搭配）之间用分隔线分开：

```
分隔线:
  宽度: 100%（弹窗内宽）
  高度: 1rpx
  颜色: --border-divider
  margin: 24rpx 0
```

## 搭配胶囊标签

```
背景: rgba(94, 138, 122, 0.12)
描边: 无
圆角: 999rpx
内边距: 12rpx 24rpx
英文: Body-S 28rpx --text-primary w700
中文: Small 22rpx --text-label
横排排列，间距 16rpx，自动换行
```
