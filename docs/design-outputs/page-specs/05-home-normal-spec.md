## 2. 纹理与氛围实现

| 效果 | 实现方式 | 规格 |
|------|---------|------|
| 整页深色背景 | `background-color: #0B1A17` | 纯色打底 |
| 水墨纹理层 | `<image>` 绝对定位，`opacity: 0.15~0.25` | 导出 750×1624 @2x PNG/WebP，从参考图中切出或单独生成；定位 `top:0; left:0; width:100%; height:100%` |
| 底部书桌场景 | `<image>` 绝对定位底部 | 从参考图切出书桌区域（约 750×400 @2x），`position: absolute; bottom: 120rpx`（Tab 栏上方） |
| 卡片毛玻璃 | `backdrop-filter: blur(20rpx)` + 半透明背景 | 如果小程序不支持 backdrop-filter，降级为纯色 `#132822` |
| 顶部状态栏融合 | `background: linear-gradient(180deg, #0B1A17 0%, transparent 100%)` | 高度约 180rpx，让状态栏和页面背景自然过渡 |

### 纹理图片切图清单

| 文件名 | 尺寸 @2x | 说明 |
|--------|---------|------|
| `bg-ink-texture-dark.webp` | 750×1624 | 深色水墨纹理，覆盖全屏，opacity 0.2 叠加在纯色上 |
| `scene-desk-dark.webp` | 750×400 | 底部书桌+书本场景，绝对定位底部 |
