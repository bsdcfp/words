## 页面特征

2 秒倒计时结束后，释义从底部推入。用户确认是否记住，点击"记住了"或等待超时。

## 释义卡片规格

```
宽度: 670rpx
高度: 自适应（最小 120rpx）
圆角: 24rpx
背景: --bg-card
描边: 2rpx solid --border-card
内边距: 32rpx 40rpx
动画: translateY(100%) → translateY(0), 150ms ease-out
```

## 释义文字颜色细则

```
词性部分（如 "n."）: Body 30rpx w700 --text-secondary（颜色稍浅）
释义部分（如 "收获；收成"）: Body 30rpx w700 --text-primary
右下角植物图标: 约 32rpx，--text-label opacity 0.4，可选装饰
```

## 声波动画（主题差异）

| 主题 | 声波形态 |
|------|---------|
| Dark | 圆形 80rpx，内含 waveform 波形线（与 07 一致），静止态竖线等高 |
| Light | 实心圆（填充 --success opacity 0.15，描边 --success 2rpx），中心显示播放按钮图标（三角形，--success，24rpx）；点击重播 |

## "轻点再听"提示（Light 特有）

light 参考图中揭示后状态在声波下方显示"轻点再听"（Small 22rpx --text-label），与 dark 图保持一致，dark 图此处不显示。

## CTA 光晕

```
box-shadow: 0 16rpx 48rpx rgba(217,119,87,0.25)（dark）/ rgba(212,147,90,0.3)（light）
```

## 超时行为

```
揭示后 3 秒内未点击"记住了":
  → 加入错词本
  → 屏幕边缘闪红（--error-flash, 300ms）
  → 自动切换下一个词
```

## 看中文回忆英文（镜像模式）

同一模板，内容互换：

| 揭示前 | 揭示后 |
|--------|--------|
| 展示中文释义（居中） | 推入英文单词+音标 |
| 无音标 | 英文 + 音标 + 播放 |
