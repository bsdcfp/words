## 页面特征

学习流程核心页。全屏深色，无 Tab 栏。单词垂直居中，自动循环播放。底部单一 CTA"记住了"。

## 特有规格

| 元素 | 规格 |
|------|------|
| 声波动画（视觉形态） | 圆形 80rpx 容器，内部为音频波形线（waveform bars，约 5 条竖线），播放时竖线高度随音频振幅变化；外圈圆形描边 2rpx --success opacity 0.4；颜色 --success-bright |
| 声波动画（播放中） | 竖线高度抖动，外圈脉动 scale 1.0→1.1，300ms loop |
| 声波动画（静止） | 竖线等高，外圈静止 |
| "轻点再听" | Small 22rpx --text-label，opacity 0.6。点击屏幕空白区域触发重播一轮 |
| 进度圆点 | 9 个（一个 list = 9 词），顶部居中。当前词用 --dot-current + 脉动 |
| 暂停提示 | 左侧边缘竖排 "‖ 长按侧边暂停"，22rpx --text-label opacity 0.5，绝对定位 left 8rpx 垂直居中 |
| CTA 光晕 | `box-shadow: 0 16rpx 48rpx rgba(217,119,87,0.25)`（dark）/ `rgba(212,147,90,0.3)`（light） |

## 播放循环

```
进入页面 → 自动播放发音 → 等待 1s → 再播放 → ... 循环 N 次（用户设定，默认 3）
循环完成后停止，等待用户操作
声波动画在播放时脉动，停止时静止
```

## "还不熟"交互

- 不用按钮，轻点屏幕空白区域触发
- 触发后重新播放一轮（N 次循环）
- 不进入错词本

## Codex 检查表

- [ ] 单词垂直居中（屏幕中心），不是顶部 1/3
- [ ] 无播放按钮，声波动画替代
- [ ] 底部只有"记住了"一个按钮
- [ ] 进度圆点 9 个，不是数字
- [ ] 自动播放发音，循环次数按用户设置
- [ ] 轻点空白区域触发重播
- [ ] 记忆图/例句不展示（藏在详情弹窗）
