# 单词项目功能点与问题梳理（基于 v2 讨论定稿）

日期：2026-05-31

---

## v2 核心方向变化

v2 的首要目标从"按艾宾浩斯遗忘曲线长期复习"调整为**完成一本单词书**。以下 v1 机制不再作为主逻辑：

- 艾宾浩斯遗忘曲线排程（1/2/4/7/15天）
- 到期复习优先级排序
- 因超过复习窗口而降级
- 长周期复习节点

主线改为：选择单词书 → 按 list 推进 → 每 list 内按 3 词一组学习 → 错词进统一错词本 → 睡前/晨间提醒复习。

## 需要移除的 v1 逻辑

当前代码中仍包含以下 v1 机制，按 v2 定稿应移除或降级为可选：

1. **艾宾浩斯复习节点**：`REVIEW_INTERVAL_DAYS = [1, 2, 4, 7, 15]` 及相关 `reviewStage`/`nextReviewAt` 逻辑
2. **超期降级**：`applyOverdueDowngrades` 函数
3. **综合风险排序**：`scoreWordRisk` 中的到期复习权重
4. **复习失败停留/降级状态机**：`nextReviewStage`、`nextReviewPatch` 等
5. **首页展示的复习节奏文案**："D+1 / D+3 / D+7"
